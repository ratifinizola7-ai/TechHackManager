# 🚀 TechHackManager

Sistema em Java voltado para a gestão e organização de hackathons, permitindo o controle e relacionamento entre participantes, equipes, mentores e alocação de espaços físicos.

---

## 📌 Funcionalidades

- Gestão de Participantes: Registro de alunos e suas linguagens de programação principais.
- Gestão de Equipes: Vínculo de projetos, membros e avaliação final.
- Mentoria: Controle de mentores responsáveis por orientar as equipes.
- Alocação de Espaço: Organização de salas, prédios e capacidade do local.

---

## 🛠️ Tecnologias Utilizadas

- Linguagem: Java (JDK 21)
- Paradigma: Programação Orientada a Objetos (POO)
- IDE recomendada: IntelliJ IDEA
- Controle de Versão: Git / GitHub
